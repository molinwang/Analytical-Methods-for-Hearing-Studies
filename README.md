# Analytical Methods for Hearing Studies

Statistical methods and R/SAS code developed by Dr. Molin Wang's group and
collaborators for hearing research, including audiometric data
analysis, evaluation of hearing assessment tools, and detection
of outlier evaluators.

## Available methods

| Method | Language | Purpose |
| --- | --- | --- |
| [Audiometric data analysis](audiometric-analysis/) | R | Analyze data from both ears using generalized estimating equations (GEE). |
| [Reliability and validity](reliability-and-validity/) | R and SAS | Evaluate hearing assessment tools using intraclass correlation coefficients (ICCs) and GEE analyses. |
| [Outlier evaluator detection](outlier-evaluators/) | R | Identify evaluators with systematically higher or lower measurements, considering false discovery rate and statistical power. |
